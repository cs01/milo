# VOLT

A 2D momentum platformer. You are Milo, a chihuahua. Three levels, hydrants for
checkpoints, instant respawn.

```bash
milo build examples/games/volt/main.milo -o /tmp/volt --release && /tmp/volt
```

Arrows/WASD move, `SPACE` jump (hold for height), `SHIFT` dash eight-way, `B`
bark, `DOWN` drop through, `R` restart, `M` music, `ESC` quit.

Bark breaks crates and kills cats and birds. A bone makes you a german shepherd —
bigger, longer bark, and it takes the next hit for you.
