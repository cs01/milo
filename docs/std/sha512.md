# std/sha512

## std/sha512

### `Sha384.bytes`

```milo
fn Sha384.bytes(input: &string): string
```

Raw 48-byte SHA-384 digest.

### `Sha384.hash`

```milo
fn Sha384.hash(input: &string): string
```

48-byte SHA-384 digest as 96-char lowercase hex.

### `Sha512.bytes`

```milo
fn Sha512.bytes(input: &string): string
```

Raw 64-byte SHA-512 digest. Use this when the digest feeds further bytes
(HMAC, key derivation) rather than a display string.

### `Sha512.hash`

```milo
fn Sha512.hash(input: &string): string
```

64-byte SHA-512 digest as 128-char lowercase hex.
